## O que e Big Data

Big Data se refere a conjuntos de dados tao grandes, rapidos ou variados que os
sistemas tradicionais nao conseguem processar de forma eficiente.

## Os "Vs" do Big Data

- **Volume:** quantidade massiva de dados.
- **Velocidade:** rapidez de geracao e processamento.
- **Variedade:** dados estruturados, semiestruturados e nao estruturados.
- **Veracidade:** confiabilidade dos dados.
- **Valor:** utilidade extraida dos dados.
