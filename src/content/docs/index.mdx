## O que é o ParaTISaber

O **ParaTISaber** reúne, de forma organizada e gratuita, os principais temas de
Tecnologia da Informação. A ideia é simples: deixar o conhecimento
aberto para quem quer aprender, do iniciante ao avançado, sem depender apenas de
cursos e livros pagos.

Serve para estudantes, autodidatas, profissionais em transição de carreira e,
tambem, para quem estuda para concursos ou certificações.

## Como contribuir

Este é um projeto de conhecimento aberto. Qualquer pessoa pode sugerir correções,
melhorar explicações ou adicionar novos tópicos. Cada página tem um link de
"Editar" que leva direto ao repositório.
